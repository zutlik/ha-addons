## How to Use This Index

Before starting any non-trivial task:
1. Scan this index for a matching skill.
2. If found: load the skill file and follow it.
3. If partially matching: use it, then note what was missing in `IMPROVEMENTS_BACKLOG.md`.
4. If missing: complete the task, then consider writing a skill.
